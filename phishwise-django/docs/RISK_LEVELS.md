# เกณฑ์ระดับความเสี่ยง

แหล่งข้อมูลจริงของระบบอยู่ที่ `detector/risk_levels.py` หากแก้เกณฑ์ต้องแก้ไฟล์นั้น ชุดทดสอบ UI และ PDF ให้ตรงกัน

| ค่าความเสี่ยงภายใน | key | ข้อความที่แสดง |
|---:|---|---|
| 0–20 | `safe` | ปลอดภัย |
| 21–40 | `mostly_safe` | ค่อนข้างปลอดภัย |
| 41–60 | `warning` | ควรระวัง |
| 61–80 | `mostly_danger` | มีแนวโน้มอันตราย |
| 81–100 | `danger` | อันตราย |

## หลักการแสดงผล

- ผู้ใช้เห็น “ระดับ” และคำอธิบาย ไม่เห็นคะแนนความน่าจะเป็นของโมเดล
- ผลของ Random Forest และ BiLSTM แสดงแยกกันเป็นระดับเดียวกัน
- ผลรวมอาจต่างจากผลโมเดล เนื่องจากมีอายุโดเมน SSL การส่งต่อ ลักษณะไฟล์ และ VirusTotal ประกอบ
- ถ้าไม่มีผลจากส่วนใด ให้ใช้คำว่า “ตรวจไม่ได้” หรือสถานะตามข้อเท็จจริง
- ห้ามใช้สีเขียวกับข้อมูลที่ไม่ได้ตรวจหรือไม่ทราบผล

## แนวทางสำหรับผู้ใช้

- ปลอดภัย: ยังไม่พบสัญญาณเด่น แต่ควรตรวจชื่อโดเมนก่อนกรอกข้อมูล
- ค่อนข้างปลอดภัย: มีความเสี่ยงต่ำ แต่ควรยืนยันแหล่งที่มา
- ควรระวัง: หลีกเลี่ยงการกรอกข้อมูลสำคัญจนกว่าจะตรวจสอบเพิ่มเติม
- มีแนวโน้มอันตราย: ไม่แนะนำให้เปิดเผยข้อมูลหรือดาวน์โหลดไฟล์
- อันตราย: หยุดใช้งานลิงก์และอย่าเปิดไฟล์

ข้อความเหล่านี้เป็นคำแนะนำเบื้องต้น ไม่ใช่การรับรองหรือคำวินิจฉัยที่แน่นอน
