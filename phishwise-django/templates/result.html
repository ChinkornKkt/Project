การตรวจสอบเนื้อหาหน้าเว็บ

ผลการวิเคราะห์ด้วยโมเดล Deep Learning (BiLSTM)

ผลลัพธ์รอบนี้: {{ content_model_result.label }}
{% if content_model_result.available %}ดึงและวิเคราะห์เนื้อหาสำเร็จ{% else %}ไม่สามารถดึงเนื้อหาหน้าเว็บได้{% endif %}

1. โครงสร้างแท็ก HTML และฟอร์มรับข้อมูล (HTML Elements)

สแกนหาฟอร์มกรอกข้อมูล (<form>), ช่องกรอกรหัสผ่าน (<input type="password">), กล่องซ่อนข้อมูล (<input type="hidden">) รวมถึงกรอบฝังหน้าเว็บ (<iframe>) เพื่อดูว่ามีการพยายามหลอกให้ผู้ใช้ป้อนข้อมูลสำคัญหรือไม่

2. คลังคำศัพท์และข้อความล่อลวง 15,000 คำ (Phishing Vocabulary)

ตรวจจับคำและวลีที่มักพบในเว็บฟิชชิ่ง เช่น การแจ้งระงับบัญชีด่วน, ยืนยันสิทธิ์รับเงิน, อัปเดตข้อมูลความปลอดภัยฉุกเฉิน โดยเทียบกับคลังคำศัพท์ฟิชชิ่ง

3. การวิเคราะห์บริบทและความหมายสองทิศทาง (Bidirectional Context)

โมเดล BiLSTM อ่านประโยคและลำดับแท็ก HTML ย้อนกลับไปข้างหน้าและข้างหลังพร้อมกัน เพื่อเข้าใจบริบทโดยรวมและเจตนาที่แท้จริง ไม่ได้ตัดสินแค่การพบคำศัพท์เดี่ยวๆ

4. การเทียบเคียงฐานข้อมูลเว็บจริงและเว็บปลอม (Zenodo Dataset)

เรียนรู้และจับคู่รูปแบบโค้ดจากชุดข้อมูลหน้าเว็บจริงและเว็บปลอมกว่า 110,000 หน้า ทำให้สามารถแยกแยะความแตกต่างระหว่างเว็บบริการทั่วไปกับหน้าเว็บเลียนแบบได้

หมายเหตุความโปร่งใส: หากหน้าเว็บมีระบบป้องกันบอท (เช่น Cloudflare) หรือบล็อกการเข้าถึง ระบบจะแสดงผลว่า "ตรวจไม่ได้" ตามข้อเท็จจริง โดยไม่เหมาว่าเป็นเว็บปลอดภัย เพื่อป้องกันความคลาดเคลื่อนในการตัดสินใจ
